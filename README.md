# 🧮 Math Quiz Game

Welcome to the **Math Quiz Game**! 🎯

This is a simple and interactive quiz game designed to test and improve your mathematical skills. Answer different math questions, challenge yourself, and see how well you can score!

## ✨ Features

- 🧮 Math-based quiz questions
- 🎯 Interactive gameplay
- 📊 Score tracking
- ⚡ Quick calculations
- 🧠 Improves mathematical thinking
- 🎮 Simple and beginner-friendly interface

## 🚀 How to Play

1. Start the Math Quiz Game.
2. Read each question carefully.
3. Select or enter your answer.
4. Continue through the quiz.
5. Check your final score and see how well you performed.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Purpose

The main purpose of this project is to create a fun way to practice mathematics while also demonstrating basic web development and programming concepts.
